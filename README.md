# FUSE Analysis at Hippo
An attempt at analysis from the bench

## About
The project analyses emoji use based on screenshots of Slack users' Frequently Used Slack Emojis (i.e. FUSE) list.

### Goals
1. Analyse Frequently Used Slack Emoji (or… FUSE) from screenshots provided
2. Present findings to whoever will listen
3. Create a Python program capable of re-use for possible future FUSE screenshots
