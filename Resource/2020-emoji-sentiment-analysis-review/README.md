# Sentiment Analysis from WhatsApp Emojis
In 2020, github user Subhasishbasak explored the possiblity of identifying how their friends were feeling through sentiment analysis based on screenshots of the friends' most used WhatsApp emojis.

The project was a success and the code was shared on github - [emoji sentiment analysis](https://github.com/Subhasishbasak/emoji_analysis)

Whilst the outcome of this sentiment analysis project is slightly different to the goals of FUSE Analysis, it is useful to reference and use as a guide for ways to extract individual emoji images and matching against the Slack emoji list.

This section goes through the code used in the emoji sentiment analysis to understand what it is doing and what can be reused as part of the FUSE task.
